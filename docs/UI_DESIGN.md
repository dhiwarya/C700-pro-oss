# UI design: Daylight and Night

The screens follow one small system so every page reads the same at arm's
length on the bars. Daylight (light) is the default; Night is the same layout
in dark colours and is what the auto theme switches to after sunset.

## Screen anatomy (240 × 320)

| band | height | what |
|---|---|---|
| status bar | 24 | key-0 chip, ride state, GPS, battery, settings gear |
| content | 248–272 | home checklist, data page, or map + field strip |
| soft keys | 24 | ride pages only: labels for the two bottom keys |

**Key-0 chip.** Flush with the top-left corner, next to key 0. When idle it
names the page key 0 goes to ("STATUS ›", "MAP ›"); during a ride it shows
the position in the page ring ("2/4 ›").

**Ride state.** A dot and REC (green), PAUSED or AUTO-PAUSED (amber), right of
the chip. Hidden when idle.

**Soft keys.** Two tabs at the bottom corners, above key 1 (bottom left) and
key 2 (bottom right): MENU / START when idle, LAP / PAUSE · hold: end while
riding, LAP / RESUME when paused. Only built where `KEY_LAP == 1 &&
KEY_RIDE == 2` (C606 Pro, CC700 Pro).

**Home.** Clock (HH:MM), date, a four-row "ready to ride?" checklist (GPS,
route, sensors, sunset) with a status dot per row, then Menu (key 1) and
Start ride (key 2) as 48 px buttons.

**Data cells.** Upper-case caption top-left (Montserrat Bold 10, 1 px letter
spacing), value in Barlow Semi Condensed at the largest size that fits
(80 / 68 / 48 / 34 / 24 / 18 px), unit in the muted colour on the value's
baseline. Wide cells under 48 px tall put the value on the caption's line,
right-aligned. 1 px dividers between cells only, no outer frame. A Route Left
cell gets a 4 px progress bar in the route colour.

**Map.** Position arrow rotated to the course while moving (dot when
standing), north marker top right, 44 px zoom buttons, scale bar in a chip
bottom left, route in the theme's route colour, ridden trail in blue.

## Colour tokens (theme.c)

| token | Daylight | Night | use |
|---|---|---|---|
| bg | #FFFFFF | #000000 | page |
| fg | #0B0D10 | #FFFFFF | values, labels |
| muted | #4B5563 | #A3ADB8 | captions, units |
| line | #CBD1D8 | #2B3139 | dividers |
| panel | #EDF0F3 | #15181D | chips, soft keys, neutral buttons |
| ok / ok_fg | #0F7A3D / white | #34D17A / black | ready, REC, Start |
| warn | #A85F00 | #FFB020 | searching, paused |
| route | #C4146E | #E8449E | route line, progress |
| marker | #1D63D6 | #3D8BFF | position |
| sel | #FFD400 | #FFD400 | menu selection (unchanged) |

All text colours keep at least 4.5:1 contrast on their own background.

## Fonts (main/fonts, regenerated by tools/gen_fonts.sh)

| font | face | sizes |
|---|---|---|
| `ui_num_*` | Barlow Semi Condensed SemiBold | 80, 68, 48, 34, 24, 18 |
| `ui_label_10` | Montserrat Bold | 10 (captions, chips, soft keys) |
| `ui_text_*` | Montserrat SemiBold | 12, 14, 16 (rows, buttons) |

Printable ASCII plus °, · and ›. `ui_text_*` fall back to the built-in
Montserrat 14 for `LV_SYMBOL_*` icons. Both families are SIL OFL 1.1
(assets/fonts/OFL-*.txt).

## Seeing changes without flashing

`tools/uisim` compiles the real UI (ui.c, datapage.c, theme.c, layouts.c,
fields.c, config.c, stats.c, sun.c, mapview.c, mapfile.c and the fonts)
against LVGL on the desktop, with stand-ins for the hardware and one fixed
ride, and renders every screen to PNG:

```sh
make -C tools/uisim MAPS=/path/to/folder/with/MAP   # the folder that holds MAP/*.map
tools/uisim/run.sh light      # -> tools/uisim/out/light/*.png
tools/uisim/run.sh dark
```

The map is drawn by the real renderer, so map style changes show up too.
